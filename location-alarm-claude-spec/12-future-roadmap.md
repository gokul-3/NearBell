# Future Roadmap

## V1.1
- saved destinations
- recent destinations
- better alarm controls
- trip templates

## V1.2
- route-aware alert
- public transport stop mode
- "alert 2 stops before" where transit data supports it
- smarter ETA/proximity messaging

## V2
- optional account
- encrypted cloud sync
- cross-device settings
- family/sharing features only with explicit opt-in

## Technical evolution
The initial architecture intentionally keeps map, location, alarm, storage, and analytics behind interfaces so providers can change without rewriting product logic.

## Important
Do not implement roadmap items before the MVP reliability criteria are met. The core value is reliable destination alerts, not feature count.
